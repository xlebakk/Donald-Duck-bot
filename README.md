# Локальный Telegram-бот на базе LLM (Llama 3.1)

Проект представляет собой локально развёртываемого Telegram-бота с поддержкой динамического контекста и контекстно-зависимого ролевого поведения.

## Стек технологий
- **Язык:** Python 3.14 (Asyncio)
- **Бэкенд ИИ:** LM Studio (Local OpenAI-compatible API)
- **Модель:** Llama-3.1-8B-Lexi-Uncensored

## Ключевые особенности
1. **Полная конфиденциальность:** Инференс модели происходит локально на CPU/GPU пользователя.
2. **Оптимизация контекста:** Автоматическая обрезка истории чата (`trim_history`) для экономии ресурсов.
3. **Асинхронный стриминг:** Потоковая выдача ответов в реальном времени.
